## 3. Главные исправления (по убыванию эффекта)

### R1. Таз: постоянная «досягаемость» на цикл плюс авторская кривая подскока; эллипс в `duty()` *(проверено на странице)*
- **WHAT:** `live/sim.js: duty`; `live/scene.js: drawRig`, блок `if (!nt && !dying) { const mL = foot(-1, uR).p … for (it…) d1 += softplus(…); … drop = Math.max(d1, d2) − …}`.
- **WHY:**
  - Подскок головы на диагонали: герой 10,8 px (11 % H), ghoul 7,2 (10 %), skeleton 6,5 (7,7 %); у нового brute 4,7 px (4,3 %), его спасает `reachSide`. Лимит qa 6 %, но qa не меряет диагональ, а на неё приходится 57 % движущихся кадров героя в демо.
  - Рывок головы за кадр 2,2–4,5 % H. В демо больше 1,5 % H в 16 % кадров диагонали и 12 % кадров вертикали.
  - Голова в полёте ниже, чем в опоре: −4,6 px на диагонали, −0,6 px вбок. Получается подскок ходьбы под бегом (§15.1).
  - Кадры: `out/hrun_dr/002.png`, голова на 79,5 px над землёй, против `009.png` на 90,3 px. Лист `sheets/hrun_dr_body.png`.
  - Первая причина: `duty()` складывает ходы `sw0·|gdx| + sw1·|gdy|`. Под 45° это 28,3 px, а нарисованная нога вмещает эллипс с ходом 16,6 px. Опорный ход на диагонали получается в 1,7 раза больше, и решатель опускает таз на каждом шаге.
  - Вторая причина: решатель работает в каждом кадре, поэтому кривая таза повторяет разнос стоп и даёт излом на касании.
- **CHANGE:**
  ```js

  const duty = (type, gdx, gdy) => { const sw = SWEEP[type]; if (!sw) return 0.5; const se = strideEff(STRIDE[type], gdx);

    return GAIT[type] === 'walk' ? Math.max(0.55, Math.min(0.65, d)) : Math.max(0.2, Math.min(0.5, d)); };
  ```

  | поворот 90° | 9,2 px (до 3,8 px/кадр) | `out/turn90`, кадры 7–12 |
  | поворот 180° | 14,1 px (до 4,7 px/кадр) | `out/turn180`, кадры 10–16, pop 6,5 % H |

- **CHANGE:** доля стойки, фаза и направление у каждой стопы свои и меняются только пока стопа в воздухе.
  ```js
  // sim.js gaitStep — в конце (o.bL/bR: доля стойки, o.uL/uR: фазы, o.dL/dR: направление хода стопы)
  const D = duty(type, o.gdx, o.gdy), moving = sp > 20;
  for (const s of ['L', 'R']) { const u = o['u' + s] ?? (s === 'L' ? o.gph : (o.gph + 0.5) % 1), air = u >= D;
    if (moving || air) o['u' + s] = (u + (moving ? sp / strideEff(st, o.gdx) : Math.max(1.5, o.prate || 2)) * DT) % 1;   // стоящая стопа без хода тела не уезжает
    if (air) { o['b' + s] += ((moving ? o.gait : 0) - o['b' + s]) * Math.min(1, DT * 14); o['d' + s] = [o.gdx, o.gdy]; }   // доля и направление меняются только в воздухе
    if (!moving && !air && o['b' + s] > 0.02 && o['u' + s] > D * 0.5) o['u' + s] = D;   // после середины опоры стопа отрывается и шагает в стойку
  }
  if (!moving && o.bL < 0.02 && o.bR < 0.02) o.gait = 0;
  ```
  В `drawRig` брать `uL = o.uL`, `uR = o.uR`, а в `foot(side, u)` вместо общих `run/tdx/tdy` использовать `o.bL/bR`, `o.dL/dR`. На старте первой шагает стопа, которая дальше позади по ходу: `o.uL = D` или `o.uR = D` в момент, когда `gait` поднимается с 0. Приёмка: в сценариях старт / остановка ×4 фазы / поворот 90° и 180° / зигзаг опорная стопа смещается в мире не больше 1 px/кадр и не больше 3 px за переход.

### R4. Brute идёт шагом: без полёта, с двойной опорой и весом *(проверено на новом риге)*; skeleton — шаг или трусца без долгого полёта
- **WHAT:** `sim.js`: `STRIDE.brute = 52`, `SWEEP.brute = [10, 5]` (05:05), `duty` с зажимом 0,2–0,5 для всех; `scene.js: drawRig` (подскок только беговой).
- **WHY:**
  - Новый brute (0,47 H/s, 22 % врагов на экране) обеими стопами в воздухе 39–48 % цикла, подряд до 0,20–0,22 с. В `out/erun_brute_d` это кадры 5–16, 30–40, 54–60. Голова в полёте не выше, чем в опоре (−0,1…−0,5 px).
  - На старом риге было 38–50 % и до 0,33 с (`sheets/brute_d_float.png`); новый лист `sheets/brute_d_new.png`.
  - У skeleton (0,96 H/s) в воздухе 40–49 % цикла, подряд до 0,17 с.
  - Двойной опоры 0 % у всех. Тяжёлое тело, которое пятую часть секунды висит, читается как «лунная походка». Короткие ноги огра (22 px) это прячут, но тело при этом качается на каждом «прыжке».
- **CHANGE:**
  ```js
  const GAIT = { hero: 'run', ghoul: 'run', skeleton: 'walk', brute: 'walk' };
  const STRIDE = { hero: 86, ghoul: 46, skeleton: 34, brute: 27, bat: 0 };   // шаг = SWEEP / D при D ≈ 0.6
  const SWEEP  = { …, skeleton: [20, 11], brute: [16, 9] };                // нога огра в 22 px показывает ±8 px (±21°), skeleton в 27 px ±10 px
  ```
  Плюс знак подскока для ходьбы (R1) и вес у brute, чтобы короткий шаг читался как тяжёлая раскачка, а не семенение:
  - боковой перенос таза к опорной стопе, `hx += run · side(stance) · 0.012 · R.h`;
  - на касании 2 кадра удержания провала: `drop += run · 0.01 · R.h · exp(−((u mod 0.5) / 0.04)²)`;
  - пыль из-под стопы в момент касания.

  **Проверено** на риге 05:03 (`whatif_walk2.js`, `out/erun_brute_*__walk2`): полёт 0 %, двойная опора 17–25 %, рывок 0,22–0,27 % H, подскок 1,9–3,1 % H, каденс 2,0–2,35 пары/с (раскачка), перекреста нет, скольжение ≤ 1 px. Для старого рига тот же результат даёт `whatif_walk.js` (stride 38): 1,42–1,67 пары/с.

### R5. Стопы врагов в толпе и при отбрасывании: шаг по фактическому смещению, при отбрасывании занос
- **WHAT:** `sim.js`, цикл врагов: `e.x += (e.vx + e.kx)·DT + sx·2.2`, затем `gaitStep(e, e.vx, e.vy, e.type)`. Толчок соседей (`sx·2.2` за шаг sim) и отбрасывание `kx/ky` в походку не попадают.
- **WHY:**
  - В демо опорная стопа скользит по миру больше 1,5 px/кадр: skeleton в 7 %, ghoul в 5 %, brute в 3 % опорных кадров. p99 2,1–4,4 px/кадр, p90 смещения тела не от скорости 0,9–1,5 px/кадр.
  - Враг шагает вперёд, пока его отбрасывает назад: 5,3 % кадров у ghoul, 6,2 % у skeleton, 8,5 % у brute.
  - `out/knock_ghoul`: обе стопы проезжают по земле 10,8 и 14,3 px; `out/knock_brute` (новый риг): 14,8 px.
- **CHANGE:**
  ```js
  const ox = e.x, oy = e.y;
  … // движение, раздвигание, pushOut, clampW
  const kb = Math.hypot(e.kx, e.ky) > 0.5 * T.sp;
  if (kb) { e.gait = Math.max(0, e.gait - DT * 12); e.skid = Math.min(1, (e.skid || 0) + DT * 10); }   // занос: стоит, наклон против толчка
  else { e.skid = Math.max(0, (e.skid || 0) - DT * 6); gaitStep(e, (e.x - ox) / DT, (e.y - oy) / DT, e.type); }   // шаг по фактическому смещению
  ```
  В `drawRig` при `o.skid` наклонить корпус против толчка (`lean += skid · 0.18 · sign(kx)·face`) и развести руки (`abd += skid · 0.4`), чтобы занос читался как поза удара, а не как скольжение.

## 5. Мелкие замечания

- **Каст: амплитуда и тело.**
  - Сейчас в `drawRig` поворот руки почти полностью гасится добавкой: `rot = (ang − ang0)·0.3 + cs·0.35` ≈ +0,05 рад. Сделать `rot = (ang − ang0)·0.3 + cs·0.1`, тогда посох наклоняется примерно на 12° вместе с рукой.
  - Замах вниз −0,2 → −0,35 и длиннее, 0,07 с: сейчас кончик опускается на 1,8 px, и замаха не видно.
  - Отдача корпуса на выстреле: `Mb` сдвинуть на `−1.5/k` по y и наклонить на `−0.04·cast` рад.
  - Голова кивает вслед: `head +0.8 px`.
- **Инерция посоха** (`drawRig`, `rot`): добавить `rot += run · 0.05 · sin(4π·uL − 1.2)`, покачивание на частоте шага с запаздыванием (§6). Сейчас при беге вниз размах 0°.
- **Укус вверх и вниз** (`drawRig`, `reachT`): при `|tg[1]| > |tg[0]|` обе кисти вести к цели через `kf`/`ang` симметрично (сейчас одна к цели, другая от неё на 12–14 px). Выпад головы по y поднять с `lunge·0.5` до `lunge·0.9`. Во время укуса гасить шаг (`gait·(1 − atk)`): ghoul сейчас кусает на полном беге (`gait = 1.0` во всех кадрах `out/bite_ghoul_*`).
- **Смерть.**
  - Сторона падения: `dieDir = Math.sign(e.kx || (e.x − S.x)) || 1` (в sim при `dieT`). Сейчас `(e.id % 2)·2 − 1`.
  - Тяжесть: `topple = 1.45·f²` вместо `pow(f, 1.35)`, отскок 0,035 → 0,1 рад.
  - На приземлении поза расслабляется: колени разгибаются, `abd → 0.2`, рука ложится, а не торчит вверх (`out/death_ghoul/030.png`, рука L в (97, 48) кропа).
  - Время падения масштабировать как `sqrt(H/72)`: brute на 34 % дольше.
- **Летучая мышь** (`drawBat`).
  - Смерть: `z` падает с ускорением до 0, `flap·(1 − die)`, `bob·(1 − die)`. Лежать 0,4 с, гаснуть после, как пешие.
  - Взмах: быстрый вниз (40 % цикла), медленный вверх со сложенным крылом, крен по `vx` (из r1).
- **Тень дальней ноги** (`drawRig → leg`): `uu = (Lf ? fL[1] < fR[1] : fR[1] < fL[1]) ? uFar : u`, то есть дальняя по глубине, а не всегда левая.
- **Удар по герою** (`drawHero`, `drawRig`): знак наклона брать от `fx` последнего события `hurt`, `lean += hitA · 0.12 · −sign(fx)`. Возврат с отскоком `e^(−12t)·cos(18t)`. Сейчас удар слева и справа дают одинаковые кадры.
- **Idle** (`drawRig`): `(1.6 + 1.6·breath)/k` переводит в rig-px константу в экранных px. Перейти на `R.h · 0.0055 · (1 + breath)` и добавить сквош корпуса `M.s(1 − 0.008·breath, 1 + 0.015·breath)` вокруг таза. У врагов вместо дыхания героя: ghoul подёргивает когтями, skeleton покачивает черепом, brute тяжело дышит плечами.
- **Отрыв стопы в глубину** (`foot()`, `offY`): та же формула Эрмита, что для x, с касательными `·0.35`. Сейчас скорость стопы в мире в момент отрыва прыгает с 0 до скорости тела.
- **Поворот на 180°**: pop 6,5 % H на кадре 7 из-за того, что `D` и `pull` скачут вместе с `gdx`. После R3 (направление у каждой стопы своё) этот pop уйдёт; пока его можно сгладить, интерполируя `D` в sim (`o.D += (duty − o.D)·DT·8`).
- **Пауза выбора улучшения**: в `step` при `S.pick` фильтр мёртвых не работает, а `S.t` идёт. В демо встречаются тела с возрастом смерти 3,08 с: падения и угасания продолжаются в замороженном мире.
- **±8 % к STRIDE на экземпляр** (из r1, не сделано): разброс каденса ghoul в демо 1,95–2,26 и идёт только от скорости. Толпа марширует почти в такт.
