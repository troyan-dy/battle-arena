## 2. Главные исправления по величине эффекта

### 1. Вечная пауза, когда оружие кончилось (критично)

**WHAT.** `sim.js: offer()`, `choose()`; `scene.js: pickPanel()`.

**WHY.**
- Когда все 4 оружия на уровне 5, на каждом уровне, не кратном 3, `offer()` даёт `kind: 'weapon', opts: []`. Мир стоит под пустым окном вечно: ни одна клавиша, клик или «Обновить» ничего не делают. Проба `probes.cjs`: `maxedOffer {opts: [], stillPaused10s: true}`.
- Автопилот на трёх сидах застревает на часах 268, 286 и 283 с (Lv 31). Это любой забег, который протянул около 4,5 минут.
- Раньше, когда остаётся одно или два оружия, окно показывает одну или две карты (`oneLeftOffer: ['bolt']`). Выглядит как поломка.

**CHANGE.**
```js
// sim.js
const STATS = { hp: {...}, spd: {...}, gold: {...},
  heal: { name: 'Лечение', desc: 'Восстановить 40 HP' }, mag: { name: 'Магнит', desc: '+30% радиус сбора' } };
function offer(S) {
  S.picks++;
  const pool = WORDER.filter((k) => S.wp[k] < WP[k].max);
  const kind = S.lv % 3 === 0 || !pool.length ? 'stat' : 'weapon';
  let opts = [];
  if (kind === 'stat') opts = ['hp', 'spd', 'mag'];
  else { while (opts.length < 3 && pool.length) opts.push(pool.splice(Math.floor(rnd(S) * pool.length), 1)[0]);
         for (const s of ['heal', 'mag', 'hp']) if (opts.length < 3 && !opts.includes(s)) opts.push(s); }   // pad, never < 3 cards
  ...
}
function choose(S, i) { ... if (STATS[id]) { S.st[id] = (S.st[id] || 0) + 1; if (id === 'hp') ...; if (id === 'heal') S.hp = Math.min(maxHp(S), S.hp + 40); } else S.wp[id]++; ... }
// magnet: HERO.MAG * (1 + 0.3 * (S.st.mag || 0)) in the pickup loop
```
В `pickPanel()` выбирать вид карты по `SIM.WP[id]`, а не по `p.kind`, чтобы смешанное окно рисовалось правильно. Кнопку «Обновить» прятать, если в пуле не больше трёх вариантов: обновлять там нечего. Проверено в памяти (вариант `rec`): автопилот проходит 300 с без застревания.

### 2. Демо и поздняя игра идут на 20 fps: виноваты проходы обводки

**WHAT.** `lib.js: L.inked()`; `scene.js: drawEnemy()`, `drawRig()`, `INKE`.

**WHY.** Тест `play.mjs perf` и `demofps`, окно 1920×1080, Chromium с Metal:

| Состояние | fps |
|---|---|
| Начало забега, 22 врага | 60 |
| Аттракт-демо, 117–136 врагов | **20–22** |
| Всё оружие 5-го уровня, 122 врага | 17–20 |
| То же, но `LIB.inked` подменён на один `draw()` | **60** |
| Обводка включена, 40 врагов | 56 |

`L.inked` вызывает `draw()` n + 1 раз. У врага n = 4, то есть 5 полных решений позы рига и около 10 частей на проход: 125 × 5 × 10 ≈ 6250 вызовов `drawArrays`, батчинга в `gl.js` нет. Орда к 2:30 доходит до лимита 170, значит каждый, кто доживёт, увидит 20 fps. Порог `livecheck.mjs --minfps 55` демо бы не прошло.

**CHANGE**, по шагам:
- **(a) Поза считается один раз.** `drawRig` собирает список `[tex, matrix, u]` и проигрывает его n + 1 раз, без пересчёта IK. Это экономит CPU.
- **(b) Одна копия обводки вместо n.** В шейдер спрайта добавить `u_inkR`: цвет обводки там, где max(alpha) по 8 отсчётам на радиусе r больше 0,5. Тогда `L.inked` = 1 ink-копия + 1 обычная, вместо 4 + 1 у врагов и 6 + 1 у пропов. Порядок «сначала вся обводка, потом все части» сохраняется, поэтому на суставах швов не будет.
- **(c) LOD.** У умирающих (alpha < 1) и у летучих мышей обводку пропускать.

Цель: ≥ 55 fps при 150 врагах и оружии 5-го уровня. Проверка: `play.mjs perf`.

### 3. Враги появляются прямо в кадре

**WHAT.** `sim.js: step()`, блок появления (`e = { x: S.x + cos·1150, y: S.y + sin·700 }`) и возврат отставших (`> 1700 → ring`).

**WHY.**
- Эллипс 1150×700 вокруг героя не помещается за кадром. Герой стоит в точке FEET (1008, 720) вида 1920×1190. До краёв: слева 1008, справа 912, сверху 720, снизу 470 px.
- **25,7 % углов** эллипса лежат внутри кадра.
- За 60 с кайта **125 из 258 (48,4 %)** новых врагов возникают со стопами в кадре, **40 (15,5 %)** — глубоко внутри.
- Сверху враг рождается в 20 px от края. Слева на углах ±150° (x = −996 при видимых −1008) — внутри кадра.
- Отрисовки появления нет, поэтому каждый новый враг — заметный «поп».

**CHANGE.** Считать точку появления от прямоугольника камеры, а не от эллипса вокруг героя. Поля: по бокам 120 px (полширины спрайта и упреждение камеры), сверху 60 px (тело уходит вверх от стоп), снизу 170 px (рост громилы 128 плюс высота полёта мыши):
```js
const a = rnd(S) * Math.PI * 2, ca = Math.cos(a), sa = Math.sin(a), ccx = S.cam[0] + VIEW.W / 2, ccy = S.cam[1] + VIEW.H / 2;
const k = Math.min((VIEW.W / 2 + 120) / Math.max(1e-3, Math.abs(ca)), (VIEW.H / 2 + (sa < 0 ? 60 : 170)) / Math.max(1e-3, Math.abs(sa)));
const e = { x: ccx + ca * k, y: ccy + sa * k };
```
Ту же функцию использовать для возврата отставших. Дополнительно в `drawEnemy` дать первые 0,25 с жизни: альфа 0 → 1 и подъём из земли на 6 px, для мышей — снижение.

### 4. Стартовый жезл не попадает в того, кто кусает

**WHAT.** `sim.js: step()`, ледяной жезл (`const base = tg ? Math.atan2(tg.y - S.y, tg.x - S.x) : ...` и `th: base + i·2π/n − 0.6`).

**WHY.** Расчёт прицела игнорирует три вещи: спираль выходит из навершия посоха (герой +37/−98 px), осколки поворачиваются со скоростью 2,1 рад/с, ось y сжата в 0,72 раза. Попадания в секунду по неподвижному врагу, жезл Lv1 (`ice_cover.cjs`):

| Расстояние | 0° | 90° | 180° | 270° |
|---|---|---|---|---|
| 45 px (укус в упор) | **0** | 1,4 | **0** | **0** |
| 90 px | 0 | 0 | 0 | 1,5 |
| 250 px | 1,4 | 0 | 0 | 0 |

Игрок видит, что оружие «бьёт само», но не бьёт того, кто его ест. Это главный провал ощущения в первую минуту.

**CHANGE** (проверено в `ice_aim_fix.cjs`: 1,3–1,5 попаданий/с на всех углах и расстояниях до 400 px):
```js
const [tx0, ty0] = tip(S), tg = nearest(S, S.x, S.y, 900), n = WP.ice.n[l - 1];
let base = S.face > 0 ? 0 : Math.PI;
if (tg) { const dx = tg.x - tx0, dy = (tg.y - 34 - ty0) / 0.72, D = Math.hypot(dx, dy), age = Math.max(0, Math.min(WP.ice.life - 0.1, (D - 40) / 300));
  base = Math.atan2(dy, dx) - WP.ice.spin * age + 0.6; }       // +0.6 cancels the −0.6 in th: shard 0 meets the nearest enemy
```

### 5. Вспышка урона: красная прямоугольная рамка поверх HUD

**WHAT.** `scene.js`: шейдер `edge`, блок в `hud()` (`G.draw(L.P.edge, …0.55·(1 − a/0.35)…)`).

**WHY.**
- В первом кадре после укуса средний R по кадру растёт с 19,7 до **54–65**, то есть на 175–230 % (`play/hurt/hurt*_a.png`).
- Форма — прямоугольная рамка, `max(q.x, q.y)` (`demo/t14.00.png`). Это эффект из примитива.
- Вспышка рисуется после слотов и миникарты, поэтому красит портрет и панели.
- Сила не зависит от урона. В демо укус на 1–3 HP (урон × 0,25) даёт ту же полную рамку.
- В окружении укус приходит раз в 0,55 с (i-frames), и экран мигает красным примерно на 1,8 Гц.

**CHANGE.**
- Рисовать в `S.render` после `L.finish`, но до `hud()`.
- Форма овальная и мягкая: `float r = length((v_uv - 0.5) * 2.0); float e = smoothstep(0.8, 1.45, r);`.
- Амплитуда: `amt = (0.10 + 0.25 * Math.min(1, e.n / 12)) * (1 - a / 0.3)`, длительность 0,3 с, в демо × 0,4.
- Новую вспышку не запускать раньше чем через 0,45 с после предыдущей.
- Отдельно постоянный сигнал низкого HP при hp < 30 %: `0.08 + 0.06 * Math.sin(GT * 6.3)` по той же маске плюс мигание полосы HP.

### 6. Кривая сложности и начало забега

**WHAT.** `sim.js`: `spawn()` (22 врага на 700–1000), `rate = min(16, 1.6 + 0.09·clock)`, `need()`. Плюс новая система событий волн.

**WHY.** Медианы по 6 сидам (`tune_variants.cjs base 6`):

| Политика | Выживание | Lv на 120 с | Первый уровень |
|---|---|---|---|
| idle | 49 с (31–82) | 3 | 18,8 с |
| circle | 75 с | 7 | 18,3 с |
| flee | 68 с | 5 | 29,5 с |
| auto | живёт, потом софтлок | 13 | — |

- В браузере стоящий на месте герой погиб на **24,5 с** (`play/idle/log.json`).
- Первый укус на 5,5 с, к 20 с потеряно 53 HP (13 укусов).
- Появление врагов 7/с на 60 с и 12/с на 115 с обгоняет рост оружия.
- У автопилота уровни иногда идут с интервалом 1,0–1,9 с. Все 4 оружия на максимуме к Lv около 30 (~4:30).
- Более ровная кривая подъёма есть у VS: первые 30 с почти без урона, 15–30 врагов на экране в первую минуту. Здесь на 60 с их ~50.

**CHANGE.** Стартовая точка — вариант `rec`, проверен в памяти:
```js
for (let i = 0; i < 14; i++) { ... d = 850 + rnd(S) * 300; ... }                                     // spawn(): thinner, farther first wave
const rate = S.demo ? 5 : Math.min(14, 0.9 + S.clock * 0.04 + Math.max(0, S.clock - 150) * 0.03);    // step()
const need = (lv) => Math.round(4 + 6.5 * lv + 0.4 * lv * lv);   // 11, 19, 27, 47 (Lv5), 82 (Lv8), 294 (Lv20)
```
Вместе с исправлениями 1, 3 и 4 медианы становятся такими: idle 70 с, circle 125 с, flee 300 с (то есть выживает). Автопилот выходит на Lv 20–21 к 5:00, интервал между уровнями от 2–7 с, софтлока нет. Дальше подкручивать через `node study/critique/measure/game/tune_variants.cjs rec 6`.

Цели: idle 60–90 с, кайт 3–5 мин, первый уровень 12–18 с.

Глубина билда. Сейчас все 4 врага отличаются только скоростью и HP. Нужен простой диспетчер событий по часам:
- 1:00 — стая мышей проносится через экран по прямой;
- 2:00 — кольцо из 40 скелетов на 600 px, сжимается;
- 3:00 — элитный громила (×6 HP, ×1,3 размер), с него падает сундук: +1 уровень оружию и 40 HP.

Это даёт «развитие → поворот» из §6 без новых ассетов.

### 7. Окно уровня: мёртвое наведение, сдвиг выбора, разрушительная R

**WHAT.** `index.html` (сборка `inp`), `sim.js: step()`, ветка `S.pick`; `scene.js: pickPanel()`.

**WHY.**
- **Наведение мёртвое.** Мышь над третьей картой — `sel` остаётся 0 (`play/picks/pick1_hover3.png`). В `index.html` нет поля `inp.moved`, а сим его ждёт.
- **Зажатая клавиша сдвигает выбор.** Окно открылось, пока держали A/D, — `sel` прыгает на соседнюю карту (2 окна из 4; проба `heldRightSel: 1`). Причина: `S.prevNav` остаётся от прошлого окна.
- **R стирает забег.** R посреди выбора перезапускает игру: часы 48,2 → 1,1, Lv 5 → 1. Esc тоже молча выбрасывает забег.
- **«Обновить» без клавиши.** Работает только мышью. Из 4 оружий и 3 карт обновление меняет максимум одну карту.
- **Выбор в окне характеристик не виден.** Цвет рамки там задан видом характеристики, выделение даёт только ×1,1 яркости.
- **Описания разнобой.** «Бьёт случайных врагов рядом» описывает оружие, у остальных — улучшение. У «Чёрной дыры» растёт и урон, но написано только про радиус.

**CHANGE.**
- В `index.html` добавить `inp.moved`, флаг на один шаг, как `click`: `pointermove → pend.moved = 1`.
- В `offer()` выставлять `S.prevNav = (inp…)`. Проще — `S.prevNav = 2`: «ждать отпускания», навигация срабатывает только по переходу 0 → ±1.
- Пока открыто окно, игнорировать KeyR и Escape. R назначить на «Обновить»: `inp.reroll`.
- В окне характеристик выделенной карте давать белую рамку 3 px, масштаб 1,04 и подсветку `L.glow` 0,3.
- Описания писать по шаблону «что растёт на этом уровне».

### 8. Звук теряет половину событий, включая сигнал уровня

**WHAT.** `sim.js`: метки времени в `hit()` (`t: S.t`), `offer()`, `choose()`; `audio.js: loop()` (`e.t > lastT`).

**WHY.** Шаг сима пишет события с **прежним** временем `S.t`, а не с новым `t`. При 60 fps за кадр проходит два шага по 120 Гц. События первого шага получают метку, ровно равную `lastT` прошлого кадра, и `audio.js` их отбрасывает. Модель кадров (`hurt_sources.cjs`):

| Событие | Сыграно / всего |
|---|---|
| dmg | 79/167 |
| die | 37/82 |
| level (circle) | 7/10 |
| pick (circle) | 7/10 |

### 9. Автопилот невидим и молча отнимает управление

## 3. Нарушенные правила

- **gamefeel §4: у каждого глагола три временных слоя.**
  - Лечение без отклика: сердце мигает **полосой XP** (`e.g !== 'coin'` включает 'heart`), полоса HP не реагирует.
  - Счётчики убийств и золота не «подпрыгивают».
  - Подбор золота не реагирует в HUD.
- **gamefeel §5, правило 4: у фоновой системы есть зацепка для игрока.** Факелы, надгробия, колонны, камни не отвечают ни на героя, ни на оружие. Классика жанра (жаровни VS): ломаются от удара и роняют сердце, монеты или магнит.
- **gamefeel §6: каждый объект что-то делает.** Стены блокируют только середину: коллайдер 120 px при спрайте 277 px (43 %). У стены сквозь неё проходит всё, что дальше 80 px от центра, а на 50 px герой обтекает её, как столб (`wall_probe.cjs`).
- **gamefeel §7: аттракт-демо проходит `tune.cjs`.** Проходит в node, но браузер идёт по другой траектории. На t = 12 с убийства 588 против 587, на 20 с позиция героя отличается на 509 px. К концу в браузере 2 выбора (взят огненный меч), в node 1. Причина — расхождение `Math.exp` и `Math.atan2` в последнем бите у V8 в Node 25 и Chromium (`determinism.mjs`), хаос 120 врагов его раздувает. demoCheck проверяет не то демо, которое видит пользователь.
- **critics §0, пункт 11 (эффекты из примитивов).** Прямоугольная рамка урона.
- **critics §0, пункт 10 (состояния читаются).** Не видно автопилота, уровня оружия в слотах, низкого HP.

## 5. Мелочи

- **Нет обработчика `blur`.** Клавиши, зажатые при Alt-Tab, «залипают», герой продолжает бежать. Нужно `addEventListener('blur', () => { for (const k in keys) keys[k] = 0; paused = true; })`.
- **Пробел и Enter для перезапуска и выбора читаются из состояния `keys`, а не из события.** Нажатие короче кадра теряется. Один раз в прогоне idle перезапуск пробелом не сработал; в отдельном тесте 4 из 4 прошли. Нужно защёлкивать keydown в `pend.act`, как сделано для `pend.slot`.
- **Лимит кристаллов 260** молча удаляет самые старые (`S.gems.splice(0, …)`). Кристаллы исчезают на глазах. Лучше сливать старые в xp5 или притягивать их к герою.
- **Молния бьёт врагов в радиусе 620 px, а под героем видно только 470 px.** Часть ударов уходит за нижний край. Можно ограничить y видимой областью.
- **Уровень оружия не виден в слотах.** Нужны точки уровня, 5 штук по 8 px под иконкой.
- **Окно «ВЫ ПОГИБЛИ»** появляется сразу и закрывает падение героя в центре. Лучше задержать на 0,6 с или смещать панель ниже, в y = 760.
- **Демо раз в 30 с обрывается без перехода.** Нужен уход в чёрное и обратно за 0,4 с на стыке петли (по `q > L − 0.2 || q < 0.2`).
- **Детерминизм.** Квантовать позиции и скорости после каждого шага (`v = Math.round(v * 1024) / 1024`), чтобы шум последнего бита не раздувался. Тогда `tune.cjs` проверяет то же демо, что видит браузер.
- **Подсказка в демо** не говорит, что любая клавиша начинает игру. Переход «демо 07:31 Lv 12 → новый забег 00:00» — резкий обрыв.
- **Герой не отталкивает кусающего.** Предложение: `e.kx += -dx * 160 / m` при укусе, чтобы касание читалось и толпа не прилипала.
- **Пучки травы** `tuft_0` ярко-зелёные, выбиваются из палитры. Нужен `prop_bush`.
