   - Скелет светлый, цвета кости: L\* p50 24 против 13.
   - Brute синий, с черепом, и крупнее по текселю в 1,5 раза.
   - Факел: серый треножник с оранжевым конусом. Он на 60 % выше референса, пламя на 100–137 px выше.

## 2. Главные исправления, по величине видимого разрыва

### F1. Земля: камень повсюду, нейтрально-оливковый, чёткий, с мелким мхом; свет площади шире (разрыв №1)
- **WHERE:** `live/scene.js: SHADERS.ground`, `render()`: пятно героя (`G.draw(L.P.glow, { u_col: [0.25, 0.75, 0.75] … 600, 400)`) и кольцо (`L.P.rune`).
- **WHY:**
  - трава закрывает около 75 % экрана, у референса около 30 % (`match_empty.png`);
  - R3 41 % против 13 %, R0+R1 29 % против 58 %;
  - камень h170 C21 против h155/242 C6–12, dE 12–20; доля пикселей с C > 8: 85 % против 63 %;
  - деталь снаружи ×0,3, пятна 37 px против 6, шаг 77 px против 11;
  - профиль L\* на r 300–600 темнее на 3–5, в центре r < 100 светлее на 13;
  - 13/48 клеток, строки 1 и 4 темнее на 0,4–0,7 стопа;
  - сама текстура хорошая (#3a4443, L 28, C 4, плиты с трещинами, `ground_tex_small.png`), портит её шейдер:
    - UV квантуются на 4 px (`w / 627.0`, где `w = floor(…/4)*4+2`), отсюда мозаика 4 px;
    - мох почти везде;
    - трава = `fbm(w*0.03)`, пятна по 30 px;
    - цвет квантуется на 28 уровней;
    - бирюзовое пятно героя.
- **CHANGE (`SHADERS.ground`):**
  ```glsl
  vec2 q = floor((v_px + u_cam) / 2.0) * 2.0 + 1.0;                       // 2-px art grid (the reference's), not 4
  if (u_hastex > 0.5) { c = texture(u_tex, q / 627.0).rgb * vec3(1.18, 1.22, 1.06); crack = 0.0; }   // was w/627 * (.92,.98,.95): lift L 28→≈36, olive not teal
  float plaza = smoothstep(1000.0, 260.0, length((w - u_home) * vec2(1.0, 1.25)));                   // was (820, 300)
  float moss = smoothstep(0.60, 0.78, n + 0.14 * (1.0 - plaza) - 0.10 * plaza + 0.10 * hv2);           // was (.52,.70, n+.36(1-p)-.08p+.16hv2): ≈30 % outside, ≈8 % on the plaza
  moss = max(moss, 0.55 * smoothstep(0.14, 0.08, dot(c, vec3(0.3, 0.59, 0.11))));                   // moss creeps into the dark joints of the texture
  vec3 grass = mix(vec3(0.03, 0.11, 0.11), vec3(0.09, 0.19, 0.15), hash(floor(q / 2.0)));            // 2-px speckle instead of 30-px fbm blobs
  grass = mix(grass, vec3(0.35, 0.42, 0.18), step(0.94, hash(floor(q / 2.0) + 3.7)));               // 6 % yellow-green flecks
  grass = mix(grass, vec3(0.01, 0.05, 0.06), step(0.85, hash(floor(q / 4.0) + 9.1)) * 0.8);          // dark gaps → p10–p90 span ≈ 20 L*
  c *= mix(0.60, 1.22, plaza);                                                                       // was mix(0.85, 1.12)
  // delete: c = floor(c * 28.0 + 0.5) / 28.0;   (flat runs)
  ```
- **CHANGE (`render()`):**
  - пятно героя: `u_col [0.25, 0.75, 0.75], u_amt 0.30` → `[0.30, 0.60, 0.68], 0.16`;
  - кольцо: `u_amt 0.8` → `0.6`;
  - в шейдере `rune` вторую окружность `0.55 * exp(-pow((r - 0.7) / 0.018, 2.0))` → `0.2 * …`, у референса одно тонкое кольцо;
  - добавить тил-диск `smoothstep(0.62, 0.40, r) * 0.25` цветом `[0.15, 0.55, 0.50]`;
  - `L.finish(… vignette: 0.72 …)` → `0.55`, угол кадра должен стать L 4–6 navy.
- **Сверить:**
  - R3 ≤ 20 %, камень площади dE ≤ 8;
  - деталь снаружи ≥ 2,0, длина пятна ≤ 8 px;
  - профиль r 300–600 в пределах ±3 L\*, r < 100 не выше 48;
  - ≥ 30/48 клеток.

### F2. Ледяная буря: чёткие когти с белым ядром, дальше от героя, постоянная дуга; без засветки героя; баг паузы

  - `live/sim.js: step()`: ветка паузы `if (S.pick)`, цикл снарядов, расчёт `age` при запуске.
- **WHY:**
  - охват 5,44 % против 3,96 % (дымка от `G.xf(hx-90, hy-90, 180, 180), u_amt .55`);

  - пауза окна уровня: `S.t` идёт, а снаряды стоят. После паузы `age = t − p.t0` включает паузу, серпы прыгают на r = 40 + 300·age за экран. Сцена рисует ленты на r 600–900 тонкими дугами (`frames/t5.00.png`: 260–440 × 150–520 и 1100–1650 × 180–260). Такое в 16 % кадров демо 0–14 с.
- **CHANGE:**
  - `sim.js step()`, в ветке паузы перед `S.t = t; S.steps++; return S;`:
    ```js
    for (const p of S.pr) p.t0 += DT; for (const h of S.holes) h.t0 += DT; S.castT += DT;   // the world waits — its clocks too
    ```
  - Радиус спирали: в `WP.ice` добавить `r0: 110, vr: 260` и использовать везде, где сейчас `40 + 300 * age`. Это три места: `sim.js` цикл снарядов, `sim.js` расчёт `age = (d − 40) / 300` при запуске, `scene.js at()`. Цель: r p10 ≈ 190, p50 ≈ 330.

    - внешнюю полосу `vec3(0.27, 0.56, 0.85)` оставить, внутреннюю `vec3(0.18, 0.34, 0.76)` → `vec3(0.27, 0.56, 0.85)` (медиана к #4590d8);

- **Сверить:**
  - охват 3,5–4,5 %;
  - медиана dE ≤ 10 от #4590d8, L p95 ≥ 85, r p50 300–360;
